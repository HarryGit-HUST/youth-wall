## 二、 访客端（学生）使用指南

### 1. 发表留言与提问
1. 访问网页，点击首页顶部 **【表达留言】** 或 **【公开提问】** 按钮。
2. **选择板块**：根据内容选择 `青年寄语`、`大学期待`、`军训感悟` 或 `招新咨询`。
3. **填写内容**：输入 1-300 字的文本（系统会自动进行敏词检测）。
4. **身份选择**：
   * 可填真实姓名/昵称（如“24级计算机张同学”）。
   * 也可勾选 **【匿名发布】**（显示为“匿名小星火”）。
5. **提交**：点击提交后弹窗提示“提交成功”，内容进入后台待审核队列。

### 2. 生成裂变海报（发朋友圈）
1. 在展墙上找到自己或喜欢的留言/寄语卡片。
2. 点击卡片右下角的 **【生成海报 🖼️】**。
3. 弹窗将自动合成带暗色星空背景、留言文本与团委标识的精美长图。
4. 点击 **【保存海报图片】** 即可保存至手机相册，用于分享至微信朋友圈或新生群。

## 三、 管理端（团委干事）日常运维指南

### 1. 管理员登录
* 打开管理端网址，输入在 Supabase 创建的**管理员邮箱**与**密码**，点击验证登录。

### 2. 审核三步法流程
管理后台上方设有 **【待审核】**、**【已放行 (已公开)】**、**【已驳回】** 三个页卡：

1. **审阅待审内容**：默认停留在 **【待审核】** 页卡，新提交的留言会按时间倒序排列。
2. **状态切换**：
   * **放行**：点击绿色 **【放行 (公开)】** 按钮，该卡片瞬间在前端展墙公开展示。
   * **驳回**：点击黄褐色 **【驳回 (隐藏)】** 按钮，该卡片移入驳回库，前端不可见。
3. **追加官方回复**：
   * 在任意留言/提问下方的输入框中输入回复（如：“*团委官方：欢迎加入团委组织部！*”）。
   * 点击右侧 **【保存回复】**，回复内容将同步加亮展示在前端卡片下方。
4. **违规处理**：若遇到恶意广告或极度不当言论，点击红色的 **【物理删除】** 永久清理数据。

## 四、 应急预案与日常维护 FAQ

#### Q1：干事忘记管理后台的登录密码怎么办？
* 登录 [Supabase 控制台](https://supabase.com/) -> 点击左侧 **Authentication -> Users** -> 找到管理员邮箱 -> 点击右侧 **`...`** 菜单 -> 选择 **Reset password** 或 **Edit user** 重新设定密码。

#### Q2：招新期间如果想新增敏感词怎么改？
* 打开本地的 `index.html` 文件，搜索 `SENSITIVE_WORDS` 数组：
  ```javascript
  const SENSITIVE_WORDS = ["打架", "色情", "赌博", "广告", "外挂", "骂人", "新增词1", "新增词2"];
  ```
  追加新词后保存并重新提交上传至 GitHub 即可。

#### Q3：招新结束后如何导出所有留言数据作为存档？
* 登录 Supabase 控制台，点击左侧 **Table Editor** -> 选择 **messages** 表 -> 点击右上角的 **Export CSV**，即可一键将全部留言及官方回复导出为 Excel 表格存档。
